# README - DOCKER scripts for creating and testing containers to run LOOPER-PCC software

## SCOPE
create a docker container to enable deployment of containers that can run LOOPER-PCC

## NEEDS
 - [ ] run python (codebase is being updated for python 3.13)
 - [ ] run PCC code in headless configuration
 - [ ] run PCC code in GUI/interactive configuration
 - [ ] pass through needed serial connections for LABJACK and ARDUINO connectivity
 - [ ] provide logging/output needed to facilitate debugging
